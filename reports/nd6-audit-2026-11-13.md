## 1. Fakta dari source (path + lokasi)

- **`/rekap` handler**: `saq-report/routes/rekapRoutes.js` L30–41 — jalur ze =
  `readCount()` ×4, jalur v8 = `read().length` ×4, lalu `res.render('rekap-pilihan')`
  L42. ⇒ Phase D mengukur **sekuens repository**, bukan request HTTP; render EJS
  di luar boundary D.
- **`readCount()` = optimasi repository + parser**: `MongoJsonRepository.js`
  L28 (`cloneJson = JSON.parse(JSON.stringify(value))` untuk `read()`), L106–130
  (`readCount()` memakai `_cacheBytes` = `Buffer.from(JSON.stringify(this._cache))`
  yang di-cache sekali — komit saq-report `8c7f2d4` judulnya eksplisit "ND-6
  candidate"). ⇒ D bukan perbandingan parser murni.
- **Seeding cache + warmup**: `scripts/bench/nd6_bench.mjs` L322–324 (cache
  Mongo di-seed manual — "tanpa MongoDB"), L395 (warmup untimed → cold path
  serialisasi pertama tidak masuk angka). D = warm cache steady-state.
- **Instrumentasi jujur**: `nd6_bench.mjs` L487–490 (`binding_calls=null` untuk
  fase D — ABI internal `readCount()` tidak terlihat dari harness).
- **Biaya open**: `ze_json/src/ondemand/document.cpp` L234–259 — `Document::open`
  = 3× `arena.allocate(slot_bytes)` + `structural_scan(src, src_size, indexes,
  src_size)` dalam satu pass; tanpa free individual sampai `ze_reset_heap`
  (`src/abi/cabi.cpp` L91, L118–123 menutup semua slot); `ze_parser_open`
  L205–206, `ze_parser_close` L461–462.
- **Copy JS→wasm**: `bindings/js/ze_json.mjs` L159–169 + L371–372 (`ze_alloc`
  + `Uint8Array.set` ke memory.buffer).
- **Anomali metadata lama**: `scripts/node-benchmark/harness.mjs` L398 —
  `version: process.versions.node` ⇒ record baseline V8 membawa
  `library.version = "26.13.0"` (versi runtime, bukan identitas library).
